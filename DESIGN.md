# DESIGN.md — Копилка / Вектор Капитал

## Контекст
- **Артефакт:** интерактивные прототипы мобильного iOS-приложения (инвестиции для новичков, РФ), просмотр в браузере: на десктопе — телефон в «студии», на мобильном — приложение во весь экран.
- **Аудитория:** новички в инвестициях; продукт для стейкхолдеров/демо.
- **Позиционирование:** нативное качество уровня Apple / WhatsApp / Revolut. Никакого «AI-лука».
- **Слова-обязательства:** нативный · спокойный · точный · доверие · без усилий.
- **Эссенция:** «как из App Store».

## Эстетика
iOS 17/18 Human Interface Guidelines, воспроизведённые дословно: grouped-фон, inset-списки, large title, таб-бар с блюром, шторки с грабером, hairline-разделители. Отличительность — не в украшениях, а в фанатичной точности системных паттернов.

**Signature move:** прототип ведёт себя как настоящее приложение — push-навигация со слайдом, шторки с пружиной cubic-bezier(.32,.72,0,1), нажатие сжимает кнопку, на телефоне открывается без рамки, во весь экран.

## Типографика
- **UI:** системный стек SF Pro (`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", Roboto`). Осознанный выбор: для нативного iOS-прототипа аутентичная типографика платформы и есть бренд-решение (как у WhatsApp/Instagram).
- **Premium-капитал:** серифный стек (`"New York", "Times New Roman", Georgia`) только для главной суммы — приём частного банка.
- Суммы: `font-variant-numeric: tabular-nums`, вес 700, letter-spacing −0.5…−1px.
- Шкала (iOS): LargeTitle 34/700 · Title1 28/700 · Title3 20/600 · Body 17/400 · Subhead 15/400 · Footnote 13/400 · Caption 12/400. Секции: 13/600 uppercase secondary.

## Токены
- Spacing base 4px; экранные поля 16px; между секциями 24–32px, внутри карточек 12–16px.
- Радиусы: списки/карточки **14** · кнопки/поля **14** · чипы/сегменты **999**. Максимум два значения на экран.
- Тень: одна — `0 1px 2px rgba(0,0,0,.04)` на карточках light; в dark — elevation светлотой, без теней.
- Кнопки: 50px, primary — заливка акцентом + белый текст; secondary — `rgba(120,120,128,.12)`; active: `scale(.97)`, 120ms.

## Крафт
- **Навигация:** таб-бар 5 вкладок (Главная · Каталог · Идеи · Обучение · Профиль), иконки — единая сетка 24, stroke 1.8. Push-экраны слайдом 320ms, back-chevron. Шторки: покупка (2 шага + успех), урок дня (3 шага + квиз).
- **Состояния:** у всех интерактивов default/active/focus-visible/disabled; пустые состояния «Фаза 2» — спроектированы, не заглушки.
- **Motion:** только transform/opacity, ease-out ≤320ms, `prefers-reduced-motion` отключает.
- **Dark (Premium):** спроектирован, не инверсия: чистый чёрный OLED-фон (аутентично iOS), карточки #1C1C1E, десатурированные акценты, золото дозировано.
- **A11y:** контраст AA (акценты затемнены под белый текст), таргеты ≥44px, focus-visible кольцо, цвет дублируется знаком (▲/стрелки).

## Слоп-аудит
Убрано из старой версии: кремовый фон-рефлекс, янтарные заливки, радиусы 24 на мелких карточках, двухслойные тени, Golos-везде. Пройдено: без Inter-как-бренда, без градиентного текста, без глассморфизма, одна тень на элемент, 60-30-10 соблюдено.
